# Brevard After Dark

An interactive 2026 Halloween event guide for Brevard County, Florida, curated by **Carrie Liotta · REAL Broker**.

## Features

- 64 event listings with organizer source links
- Search and filters for date, audience, scare level, and free events
- Favorites and itinerary tools stored in the visitor's browser
- Responsive original gothic-comedy visual design
- Privacy-friendly aggregate visit counter (one count per browser session)

## Live sites

- GitHub Pages: https://carrieliotta-droid.github.io/brevard-after-dark/
- Cloudflare Pages: https://brevard-after-dark.pages.dev/

Event information was researched in October 2026. Visitors should confirm details with each organizer before attending.

## Local preview

Open `index.html` directly, or run any static web server in this directory.
